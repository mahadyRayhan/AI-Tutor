Why this preserves the guarantee

RULE 1 · 5

A head start carries zero evidence

The boost seeds the prior only. Certification needs n ≥ 3 real answers per tier, so a seed can never certify — and an uncertified topic can never become a source. No snowballing.

RULE 2

Small, capped, per tier

Boost = κ·strength with κ = {0.15, 0.06, 0.01}, capped at {0.50, 0.15, 0.02}. Applied competence (code) barely transfers; recall (quiz) transfers most.

RULE 3 · 4

Applied once, then performance rules

Seeded at first touch. After that, real answers and between-session decay both pull toward the default prior — a head start never holds a score up against real failure.

RULE 6

Only doubt flows downhill

Lowering a prerequisite reduces the head start it passes to zero-evidence neighbors. A student can never drag a topic up to inflate its dependents — the channel is downward-only.

RULE 7

The gate reads certified mastery

Content unlocks on ever_certified, never on the head-started posterior — so a boost can move the starting line but never open a door the student hasn't earned.

PROOF

Pointwise dominance

Every posterior under the head start is ≤ its counterpart without it for any answer sequence. No topic certifies earlier, and none certifies that otherwise wouldn't.
