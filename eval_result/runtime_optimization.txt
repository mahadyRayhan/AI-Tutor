### The "Before & After" Calculation

We have data points from our previous conversations. Let's formalize them.

#### 1. Baseline System (Slow Path)
*   **Architecture:** Serial execution, LLM-based Classification, No Streaming.
*   **Steps:**
    1.  Intent Class (LLM): ~1.5s
    2.  Entity Extract (LLM): ~1.5s
    3.  Retrieval (Embed): ~2.0s
    4.  Graph Check: ~0.1s
    5.  Answer Gen (LLM): ~6.0s
    6.  Suggestion Gen (LLM): ~2.0s
*   **Total Serial Latency:** $1.5 + 1.5 + 2.0 + 0.1 + 6.0 + 2.0 \approx \mathbf{13.1 \text{ seconds}}$
*   **Time to First Token (TTFT):** **13.1 seconds** (User waits until everything is done).

#### 2. Optimized System (Current State)
*   **Architecture:** Local Classification, Parallel Async Generation, Streaming.
*   **Steps:**
    1.  Intent + Entity (Local): **0.14s** (Saved 2.86s)
    2.  Retrieval: 2.0s
    3.  Graph Check: 0.1s
    4.  Answer + Suggestions (Parallel): `max(6.0, 2.0)` = **6.0s** (Saved 2.0s)
*   **Total Processing Time:** $0.14 + 2.0 + 0.1 + 6.0 \approx \mathbf{8.24 \text{ seconds}}$.
*   **Time to First Token (TTFT):** **2.24 seconds** (User sees text immediately after Retrieval).
