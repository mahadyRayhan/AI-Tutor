SAGE · Cognitive Access Control · as built

The Dynamic DAG

The instructor's map never changes. What changes is how much each student gets from each topic on it. First it depends on how far ahead the topic is. Then it depends on three metacognitive traits, and each trait can only make access stricter.

1 · The static DAG

The instructor's map

Nine topics and eight prerequisite links (CANONICAL_PREREQ_EDGES). Every student gets the same map. After Variables it splits into two branches: Control Flow (Functions, Arrays, Strings, Structures, File I/O) and Pointers (Memory Allocation). Branches matter later, because overconfidence travels along them.

2 · Mastery on the nodes (K)

Distance decides the starting access

A topic is mastered when the student is certified on it: 0.95 or higher on all three kinds of evidence (quiz, micro-challenge, code), with at least 3 of each. They keep it while all three stay at 0.75 or higher. The next topics are the ones whose prerequisites are all mastered. Access is counted in steps from what the student has mastered:

full access
Mastered, or 1 step ahead

Everything the tutor can give, including code for their problem.

2 sentences
2 steps ahead

A two-sentence answer, then why the missing prerequisite matters.

1 sentence
3 or more steps ahead

A one-sentence answer, then why the missing prerequisite matters.

Code: the region gate in cac_graph.decide() sets rung = ORIENT and orient_sentences = 2 if far ≤ 1 else 1. This step uses mastery only. Everything after it is metacognition, which can only tighten what this step allows.

3 · Metacognition on top (C)

Which traits travel through the DAG, and how

Three traits are built. Only overconfidence travels along the map. The other two apply to the whole student: they change every topic at once, and branches play no part. All three figures show the same student, who has mastered Variables and Control Flow.

Overconfidence · Phase 4

Flows down its own branch

The student keeps getting Control Flow questions wrong that the model expected them to get right. They don't know they're wrong, so they will build Arrays, Strings and File I/O on the broken idea.

So every topic after Control Flow on its branch now requires Control Flow ≥ 0.80 instead of 0.75. If the student is below that, they are sent back to revisit Control Flow. Control Flow itself stays open, and so do Pointers and Memory Allocation, which are on the other branch.

Cognitive load · Phase 3

Shrinks how far ahead they can reach

A student who is overloaded and reaches far ahead isn't curious. They're drowning. So their reach shrinks, and a topic beyond it is redirected to the nearest topic they can absorb. Here File I/O is replaced with Strings. The request is never simply refused.

Help-seeking · Phase 2

Caps every topic at hints

The student gives up immediately and skips often, reaching for the answer before trying. Code given now would answer the give-up rather than the question. So topics that were fully open drop to hints, no code. Topics already limited to a short answer stay as they were.

4 · Metacognition × distance

How each trait changes 1-, 2- and 3-step access

This is the same student, mastered in Variables and Control Flow. Each row switches on one trait, and the last row switches on all of them. Every cell comes from the same logic as decide() plus the gatekeeper, and shows what the student gets when enforcement is on.

When traits combine, the strictest one wins. The disclosure level takes the lowest, the mastery bar takes the highest, and the nearest redirect wins. All of this happens in one function, _tighten, which has no way to loosen anything. Formally, M(C,K,S) ⊆ M(C,K): metacognition can only shrink what mastery allows.

Shadow by default. Every turn forms and logs a full decision (cac_access_event, cac_edge_threshold), but students are affected only when SAGE_CAC_ENFORCE_ENABLED is on. Every answering path, both Socratic and Scaffolding, runs _apply_cac first.

Known limits. (1) Only overconfidence follows branches. Load and help-seeking apply to the whole student. (2) Overconfidence raises a bar rather than lowering the disclosure level. (3) Sentence and hint caps are prompt instructions; nothing filters the output. (4) The gatekeeper's "anyway" / "I know" override skips the overconfidence bar along with the ordinary prerequisite check. (5) Students can't see this map in the tutor yet.
