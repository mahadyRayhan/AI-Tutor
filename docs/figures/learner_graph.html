The learner model as a graph that grows

A cognitive-diagnosis model draws its picture once, from a fixed test. SAGE's grows with the session: nodes appear only as the student generates evidence, and each node firms up as evidence accumulates. Reading a node

Every node carries two numbers, not one

Classic knowledge tracing reports mastery alone — a point estimate with no sense of how sure it is. SAGE adds a second axis: confidence, the density of evidence behind the estimate. Early in a session mastery may look high off one lucky answer, but the thin ring says don't trust it yet — and it's this confidence that gates when the consistency detector's anomaly signal becomes reliable.

The data model

One graph, all the tracked knowledge

A single typed schema over the concept DAG. Two parts meet at the evidence: a per-topic competence lattice (mastery, confidence and decay for each tier of a concept) and a per-session envelope (the cognitive, affective, metacognitive and motivational signals). Evidence has one foot in each — it updates a tier and is tagged with the session state.

A data structure, drawn once — not a snapshot per moment. It stays live through three operations: insert (evidence adds nodes), update (tier mastery + confidence move), and decay (values fall without practice). Concepts, tiers and evidence are per-topic; the session-state block is per-learner, across all topics.

Positioning — kept honest

What's borrowed, what's earned

Borrowed — concede it

  • Graphs of learner state — the Open Learner Model tradition.
  • Prerequisite DAGs and Bayesian student networks.
  • Multi-attribute competence — the defining move of cognitive-diagnosis models.

Earned — the combination

  • Nodes instantiate lazily and grow with evidence — dynamic, not a fixed set.
  • Each node carries mastery + evidence-confidence.
  • Split by depth of knowing (declarative / procedural / applied), fused conjunctively, and it can decay.
  • Annotated by live affect & metacognition, and read by a security detector.
